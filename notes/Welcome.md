# Welcome to your Notes

This is your local note-taking app powered by Monaco Editor.

## Features
- **Monaco Editor** — the same editor as VS Code
- **Live Preview** — see rendered markdown as you type
- **Templates** — create notes from templates with `Ctrl+T`
- **Tags** — add YAML frontmatter tags to any note
- **File Tree** — organize notes in folders

## Getting Started
Open the `Getting Started` folder to learn more.
