# Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+T` | New note from template |
| `Ctrl+S` | Save current note |
| `Ctrl+P` | Command palette / search |
| `Ctrl+\` | Toggle editor/preview split |

## Editor Tips

The editor supports full VS Code keybindings including:
- Multi-cursor: `Alt+Click`
- Find/Replace: `Ctrl+H`
- Format: `Shift+Alt+F`
